Guides · Gantt

Free Power BI Gantt chart with milestones

Use DataLund Gantt when you want tasks, progress, groups, and milestones on one timeline — without a paid visual or a custom Deneb spec.

1. Install the visual

  1. Download ganttChart.pbiviz (or the full suite zip).
  2. In Power BI Desktop: Visualizations → … → Import a visual from a file.
  3. Pick the .pbiviz and add DataLund Gantt to the page.

2. Bind the minimum fields

  • Task — work item name
  • Start Date
  • End Date

Optional later: Group, Resource, Progress (0–1 or 0–100). Starter file: GanttSampleData.xlsx — open Start here first.

3. Mark milestones

A milestone is a zero-duration task: set Start Date and End Date to the same day. DataLund Gantt draws it as a milestone marker on the timeline.

4. Useful format options

  • Density — Compact / Comfortable / Large / Custom (Format → General)
  • Color by — Default / Resource / Group / Task
  • Time window — optional 3 / 6 / 9 / 12 months from today
