Project overview: Task List + Gantt + Resource Load

Task List picks the project. Gantt shows when. Resource Load shows who. One overview — three angles — on a shared field model.

1. Get the suite files

  1. DataLundSuite.zip — all three .pbiviz files.
  2. DatalundSuiteSample.xlsx — open the Start here sheet first, then load Projects + Tasks into Power BI.

2. Import all three visuals

Import each .pbiviz from a file (Visualizations → … → Import a visual from a file). Place Task List, Gantt, and Resource Load on the same report page.

3. Bind the shared model

  • Task List — Project (required); keep RAG, Project lead, Progress, dates up to date. See Task List help.
  • Gantt — Task, Start Date, End Date on the Tasks grain. See Gantt guide.
  • Resource Load — Resource, Task, Start Date, End Date. See Resource Load guide.

Role names stay stable across visuals even when labels differ (Project = Task, Project lead = Resource, RAG = status). Details: Support → Shared suite fields.

4. Cross-filter the page

Click a project in Task List — Gantt and Resource Load should follow. That is the suite test: one selection, three angles on the same work.

Why not one mega-visual?

Each visual keeps one job. You can use Gantt alone, or grow into the full overview without rebuilding your columns. Free to download; no network calls from the visuals.
