Guides · Resource Load

Show resource load over time in Power BI

DataLund Resource Load answers who is busy when — people or teams as rows, assignments as bars, overlaps stacked in swimlanes.

1. Install

  1. Download resourceLoad.pbiviz.
  2. Power BI Desktop → Import a visual from a file.

2. Required fields

  • Resource — person or team
  • Task
  • Start Date and End Date

Same suite names as Gantt — reuse the columns you already maintain. Starter: ResourceLoadSampleData.xlsx.

3. How load is shown

  • Overlapping assignments on one person stack in small vertical lanes.
  • A numeric load badge shows peak concurrent assignments in the visible window.
  • Optional progress fill when Progress is bound (0–1 or 0–100).

4. Format tips

  • Color by — Single fill / By task / By concurrency
  • Density — Compact / Comfortable / Large / Custom
  • Time window — 3 / 6 / 9 / 12 months from today
