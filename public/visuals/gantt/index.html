DataLund Gantt

A Gantt chart for Power BI. Tasks, progress, milestones, and groups on one timeline.

AppSource Help page. For questions, use Support.

Features

  • Task bars with progress fill
  • Milestones (zero duration)
  • Collapsible groups and resource colors
  • Today line and weekend shading
  • Cross-filter and tooltips
  • No network calls — runs in the Power BI sandbox

Fields

  • Task and Start Date (required)
  • End Date and/or Duration
  • Optional: Progress, Group, Resource, Tooltips
