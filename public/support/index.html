Shared suite fields

Starters only include columns a project manager keeps current. All three visuals share these names so one model drives the page.

  • Task / Project — work item or project name
  • Start Date · End Date
  • Progress — 0–1 or 0–100
  • Group — phase / parent (on Tasks in the starter)
  • Resource — task assignee · Project lead — project owner
  • RAG — status when bound (status; Red / Amber / Green or Rød / Gul / Grønn)

Duration and Tooltips are optional later — not in the starter Excel. Download DatalundSuiteSample.xlsx — open Start here first.

Before you email

  1. Use the latest .pbiviz from datalund.no.
  2. Gantt: bind Task, Start Date, and End Date. Resource Load: bind Resource, Task, Start Date, and End Date. Task List: bind Project; add RAG and Progress for a PMO pulse page.
  3. Include Power BI version, visual version, and a field-well screenshot if you can.

FAQ

  • Where do I start? Download DatalundSuiteSample.xlsx, open the Start here sheet, then import the visuals. Step-by-step: Guides.
  • Do the visuals call the internet? No. They run in the Power BI sandbox with no network access.
  • Are they on Microsoft AppSource? Not yet — download the .pbiviz files from this site for now.
  • What changed in the latest build? See the changelog.
